## Week 1

### Day 1

#### 1. ✅ What did I accomplish?

- Ich habe meine komplette Entwicklungsumgebung eingerichtet: VS Code konfiguriert und den Paketmanager `uv` installiert.
- Ich habe ein neues Projektverzeichnis erstellt und FastAPI installiert.
- Ich habe meine erste API mit FastAPI geschrieben und dabei die Decorators `@app.get` kennengelernt.
- Ich habe insgesamt 6 funktionierende Endpunkte erstellt (die 3 aus der Vorlesung und die 3 für die Hausaufgabe: `/square`, `/student` und `/double`).
- Ich habe gelernt, wie man die API mit `uv run fastapi dev` startet und sie über die automatische Dokumentation unter `/docs` testet.
- Zuletzt habe ich mein lokales Git-Repository mit `git init` initialisiert und meinen ersten Commit gemacht.

---

#### 2. 🚧 What challenges did I face?

- Bei der Installation von `uv` unter Windows PowerShell gab es anfangs das Problem, dass der Befehl `uv` nicht erkannt wurde ("The term 'uv' is not recognized").
- Als ich FastAPI hinzufügen wollte, bekam ich den Fehler "No `pyproject.toml` found".
- Ich war anfangs etwas verwirrt darüber, was genau mit "Submit main.py to course platform" gemeint war und ob ich die Datei irgendwo auf einer Webseite hochladen muss.
- Das automatische Skript von `uv init` hat einen Print-Befehl generiert, der nicht zum FastAPI-Code aus den Vorlesungsfolien passte.

---

#### 3. 💡 How did I overcome them?

- Das `uv`-Pfad-Problem ließ sich beheben, indem ich VSCode und das integrierte Terminal komplett neu gestartet habe, damit die Umgebungsvariablen von Windows neu geladen wurden.
- Den Fehler mit der fehlenden `.toml`-Datei habe ich gelöst, indem ich strenger auf die Reihenfolge geachtet habe: Erst `uv init` (um das Projekt zu initialisieren), und erst danach `uv add fastapi[standard]`.
- Ich habe gelernt, dass GitHub unsere "Course Platform" ist und das Einreichen bedeutet, dass wir die Dateien mit `git add` und `git commit` versionieren.
- Den falschen Initial-Code in der `main.py` habe ich einfach gelöscht und mit dem korrekten `FastAPI`-Import aus den Folien überschrieben.
